## La organizacion del diseño

Nivel -> Atomos
Componentes -> Botones,Textos, Imágenes
Descripcion ->Elementos base como <Text>, <Image>, <View>
-----------------------------------------------------
 Nivel -> Moleculas
Componentes -> Card, CardSeconds, CardTree
Descripcion -> Pequeños conjuntos visuales que muestran información de canciones o playlists
-----------------------------------------------------
Nivel -> Organismo
Componentes -> Header, Navegation
Descripcion -> Agrupaciones mayores que componen zonas completas de la UI
-----------------------------------------------------
Nivel -> Pantallas
Componentes -> App.tsx (HomeScreen)
Descripcion -> Contiene la estructura general de la aplicación
-----------------------------------------------------
